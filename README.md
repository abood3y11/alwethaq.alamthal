# مؤسسة الوثاق الأمثل التجارية — صفحة الهبوط

صفحة هبوط عربية (RTL) لخدمات توريد وتشغيل القوى العاملة. تصميم داكن بتخطيط تحريري،
حركة مربوطة بالتمرير عبر GSAP ScrollTrigger + Lenis — بدون WebGL وبدون خطوة بناء.

## الملفات

| الملف | الوصف |
|---|---|
| `index.html` | الصفحة كاملة (HTML + CSS + JS في ملف واحد) |
| `assets/brand/` | العلامة والأيقونات — `favicon.ico` · `favicon-256.png` · `apple-touch-icon.png` · `mark-512.png` |
| `assets/workers/` | صور الكوادر الشفافة (PNG بخلفية شفافة) |

> العلامة الحالية شعار حرفي مبني كـ SVG داخل الصفحة (حلقتان متشابكتان = «وثاق»).
> عند توفّر شعار رسمي، استبدل وسمي `<svg>` في `.rail-mark` و`.brand`، وأعد توليد الأيقونات في `assets/brand/`.

## بنية الصفحة

```text
شريط جانبي ثابت (نقاط تنقّل + السجل التجاري)  ← يظهر من 1180px فأعلى
شريط علوي شفاف يتحوّل لمعتم عند التمرير
↓ Hero — عنوان ضخم يُكشف سطراً سطراً + صورة الفريق بعمق متعدد الطبقات
↓ شريط نصوص متحرك (Marquee)
↓ من نحن — إضاءة النص كلمة كلمة مع التمرير + صورة الكوادر
↓ الخدمات — تمرير أفقي مثبّت (6 لوحات) ← عمودي على الجوال
↓ الجولة — أربعة مشاهد مثبّتة بصور العمال الشفافة
↓ الكوادر — عمود ثابت لاصق تتبدّل صورته مع الصفوف
↓ كيف نعمل — خط زمني يُرسم مع التمرير
↓ دعوة للتواصل + نموذج «اطلب فريقك»
↓ تذييل بالاسم الضخم المفرّغ
```

## ربط نموذج «اطلب فريقك» بـ Google Sheets

1. أنشئ ملف **Google Sheets** جديد من [sheets.new](https://sheets.new).
2. من القائمة: **Extensions ← Apps Script**.
3. احذف الكود الموجود والصق محتوى `apps-script/Code.gs` ثم احفظ.
4. اضغط **Deploy ← New deployment**، النوع **Web app**:
   - **Execute as:** Me
   - **Who has access:** Anyone
5. وافق على الأذونات، وانسخ رابط الـ Web app (ينتهي بـ `/exec`).
6. افتح `index.html` وضع الرابط في `SHEETS_ENDPOINT`.

الحقول المرسلة: `name` · `company` · `phone` · `email` · `service` · `workers` · `project_details`.

> ⚠️ الرابط الموجود حالياً في `SHEETS_ENDPOINT` هو رابط النشر القديم — أنشئ نشراً جديداً
> باسم المؤسسة الحالية واستبدله، وإلا ستصل الطلبات إلى الجدول القديم.
>
> عند تغيير حقول النموذج يجب تحديث ترتيب الأعمدة في `apps-script/Code.gs` بنفس الترتيب.

## التشغيل محلياً

افتح `index.html` مباشرة في المتصفح — لا يحتاج خادماً. المكتبات (GSAP، ScrollTrigger، Lenis) تُحمَّل من CDN.

سلوك التدهور اللطيف:
- **تعذّر الوصول للـ CDN** → تعمل الصفحة كاملة، تظهر المشاهد بشكل ثابت والأقسام تُكشف عبر IntersectionObserver.
- **`prefers-reduced-motion`** → لا تثبيت (pin) ولا تمرير أفقي، والصفحة تقصر من ~14000px إلى ~8900px مع بقاء كل المحتوى مقروءاً.
